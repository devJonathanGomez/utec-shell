# utec-shell

Repositorio de ejercicios de Shell desarrollados para aprender y practicar el uso de Bash y comandos básicos de Linux.

Los ejercicios abarcan conceptos fundamentales como navegación por el sistema de archivos, listado y manipulación de archivos y directorios, enlaces simbólicos, permisos, rutas y ejecución de comandos mediante scripts Bash.

## Proyectos

* `basics/` — ejercicios básicos de Shell y Bash.

Todos los scripts están diseñados para ejecutarse en Ubuntu 22.04 LTS.
